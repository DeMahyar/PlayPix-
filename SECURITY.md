# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

PlayPix is designed as a local-first, offline application with zero telemetry, remote accounts, or cloud synchronization.

If you discover a security vulnerability (such as an issue with IPC bridge channel isolation, unsafe file path parsing, or potential prototype pollution):

1. **Do not create a public issue**.
2. Please open a draft GitHub Security Advisory on the repository or contact the core maintainers privately.
3. Include detailed steps to reproduce the issue and your operating system environment.
4. We aim to acknowledge receipt of vulnerabilities within 48 hours and release patches promptly.
